## What it does

Maintains a growing set of markdown pages (per district, a market overview, a preferences page) that accumulate knowledge across runs — so the agent's "understanding" compounds instead of being recomputed statelessly each run. See the [knowledge-layer decision](../decisions/llm-wiki-knowledge-layer.md).

## Where it lives

`src/apartment_agent/wiki/` (schema in `WIKI_SCHEMA.md` at repo root):
- `store.py` — `FilesystemWikiStore(root)`: one `<slug>.md` file per page.
- `pages.py` — pure page rendering.
- `ingest.py` — `WikiIngestor`: regenerates affected pages after a run.
- `lint.py` — `WikiLinter`: reports health problems.

## The core split: code owns numbers, LLM owns prose

Every page mixes two kinds of section, marked with HTML comments:

- `<!-- BEGIN/END auto:name -->` — **code-owned**, deterministic. Stats tables and listing lines are generated by `stats_table` / `listing_line`. **The LLM never authors a number.**
- `<!-- BEGIN/END llm:synthesis -->` — **LLM-owned** prose. Regenerated only when a router is available.

Because the sections are delimited, regenerating the auto sections leaves the LLM prose intact and vice-versa. This is the safety property that makes an LLM-written wiki trustworthy: hallucination can't touch the figures.

## Interface

- `pages.py` (pure): `find_wikilinks("[[slug]]")`, `stats_table(...)`, `listing_line(...)`, `render_district_page(...)`, `render_market_overview(...)`, `render_preferences(...)` (folds `PreferenceSignal` into an `auto:learned` section).
- `ingest.py`: `WikiIngestor(store, router=None)` — regenerates only the affected district pages + market overview + preferences. `_synthesize` uses `router.complete(tier=CHEAP, max_tier=MEDIUM)` and **preserves prior prose on any failure or when no router is set**.
- `lint.py`: `WikiLinter.lint(today, corpus, stale_days=14)` — findings of kinds broken-link / orphan / stale / gap; deterministic, **no auto-fix**.

## Safety

Scraped, attacker-controllable text used in synthesis is wrapped in `<listing>...</listing>` with a system instruction to treat it as data and never follow instructions inside it. See [resilience & safety](../decisions/resilience-and-safety.md).

## Config / Settings keys that tune it

- `enable_wiki` (True) — toggles the whole layer.
- `wiki_dir` (default `wiki`) — where pages are written.
